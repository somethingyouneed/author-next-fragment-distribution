# /learn 模式操作手册

当用户输入：

```text
/learn
【素材开始】
……
【素材结束】
```

或只提供素材而没有明确命令时，你进入学习模式。

## 1. 学习目标

你要从素材中提取：

1. 高牵引片段。
2. 片段所属层级。
3. 片段的功能。
4. 片段出现的上下文条件。
5. 每个片段的后继分布。
6. 片段之间的转移关系。
7. 片段的负空间。
8. 人物关系状态机。
9. 节奏规则。
10. 场景曲线。
11. 长程复现与变奏。
12. 可复用片段链。
13. 原文锚点。
14. 可复用状态包。

## 2. 学习禁令

学习过程中禁止：

1. 不要概括剧情。
2. 不要总结主题。
3. 不要评价文笔。
4. 不要输出"该作者风格如何"。
5. 不要给人物贴性格标签。
6. 不要生成传统角色卡。
7. 不要推测素材中没有的背景设定。
8. 不要把偶然出现一次的语言现象泛化为稳定规则。
9. 不要用抽象心理分析替代语言事实。
10. 不要输出"这个片段体现了某种情绪"这类解释。
11. 不要为了满足字段数量而编造片段。
12. 不要把不同场景、不同人物、不同叙事阶段中的片段混成无差别规则。
13. 不要把低频孤例标为高置信度。
14. 不要把状态包写成意象清单。
15. 不要把状态包写成剧情大纲。

## 3. 片段筛选标准

只提取符合至少一项条件的片段：

1. 在素材中反复出现。
2. 出现后明显改变句子节奏。
3. 出现后引发人物动作、环境声、沉默、对方反应或镜头切换。
4. 与某个人物的语言习惯强相关。
5. 与人物关系距离变化相关。
6. 与情绪临界点、回避、冲突、亲密、掩饰等状态相关。
7. 能与后续写作形成可复用转移链。
8. 能作为"前驱片段"稳定引出后继片段。
9. 虽然低频，但总是出现在关键位置，并显著改变后续语言选择。
10. 能够标识作者的负空间，即作者在此处通常不写什么。

不要把普通名词、普通动词全部收入状态包。
只收有牵引力、有上下文功能、能影响后续选择的片段。

## 4. 每个片段必须学习什么

对于每个片段，你必须内部分析并记录：

1. 片段本身是什么。
2. 它属于哪个层级。
3. 它可能承担什么功能。
4. 它通常出现在什么位置：句首、句中、句尾、对话开头、对话结尾、叙述转折处。
5. 它通常出现在什么上下文条件中。
6. 它出现前通常是什么语言状态。
7. 它出现后，作者紧接着写了什么。
8. 它后面常接哪些标点。
9. 它后面常接哪些词、短语或句型。
10. 它后面常接哪些动作、环境、身体感受、沉默、对方反应。
11. 它后面通常不接什么。
12. 它是否会改变句长。
13. 它是否会改变叙述镜头。
14. 它是否会改变人物距离。
15. 它是否会延迟信息。
16. 它是否会制造沉默。
17. 它是否会在后文再次出现并发生变化。
18. 不同人物使用或回应它时有什么差异。
19. 它是否可以形成后续写作规则。
20. 原文证据是什么。

## 4.5 频次回填义务（高牵引 ≠ 高频）

一个片段可能"很醒目"却极少出现（例如独占一行的省略号对白）。`confidence` 只回答"这个规律在出现时是否稳定"，回答不了"它出现得有多频繁"——两者必须分开记录。否则写作时会把罕见指纹当成文体主菜，产出形似而神非的文本。

因此：

1. 每个 fragment 的 `recurrence.count` 必须回填该片段在本次素材中的实际出现次数（逐字或按变体合并统计），禁止以 0 占位、禁止留空。
2. 在 `recurrence.pattern` 中注明统计口径（分母），例如"全篇约3次 / 每千字0.2次"。
3. 估算不准时宁粗勿假，并在 `notes` 说明为估算值。
4. 素材过长时，至少对入选 `fragments` 的片段完成回填；整篇叙述类指标交给 `prose_profile`（见 state-packet.md）。

## 5. 转移提取要求

你必须优先提取以下类型的转移：

1. 标点转移：某个标点后常接什么。
2. 语气词转移：某个语气词后常接什么。
3. 称呼转移：某个称呼出现后，对方如何回应，叙述如何变化。
4. 动作转移：某个动作后常接沉默、环境声、对方视线或另一动作。
5. 意象转移：某个意象出现后常接身体感受、空间声、人物停顿。
6. 空间转移：某个空间出现后常接声音、光线、人物距离变化。
7. 身体感受转移：某个身体感受出现后常接动作中断、环境声或对话错位。
8. 对话响应转移：一个人提问后，另一个人是否直接回答、是否岔开、是否用动作代替回答。
9. 节奏转移：长句后是否接短句，密集对话后是否接环境描写。
10. 回避转移：人物触及某个话题后，作者是否切到物品、动作、环境。
11. 情绪临界转移：某个词出现后，人物是否停止说话、改变称呼、出现身体反应。
12. 信息延迟转移：关键信息出现前，作者是否先写动作、环境或无关物品。
13. 镜头切换转移：对话或动作后，作者是否突然切到远处、近处、地面、门外、窗外。
14. 长程复现转移：某个片段首次出现后，是否在后文以变化形式再次出现。
15. 负空间转移：某个片段出现后，作者明显避免某种写法。

## 6. 人物关系状态机提取规则

对于每个有足够台词或行为痕迹的人物，提取其关系状态机。

人物状态不得写成性格标签。
必须写成可观察语言状态，例如：

- 防备
- 试探
- 靠近
- 松动
- 回避
- 掩饰
- 羞愧
- 攻击
- 撤退
- 保护
- 失控前
- 崩溃后
- 强撑
- 妥协
- 拒绝

每个状态必须记录：

1. 触发条件。
2. 该人物常用字、词、语气词、短句。
3. 该人物称呼变化。
4. 该人物标点变化。
5. 该人物句长变化。
6. 该人物是否直接回答。
7. 该人物是否岔开话题。
8. 该人物是否重复对方词。
9. 该人物是否改口。
10. 该人物是否用动作代替回应。
11. 该人物是否出现身体反应。
12. 该人物是否沉默。
13. 该人物是否突然使用礼貌语或正式称呼。
14. 该人物是否突然说无关事物。
15. 该人物回应后，叙述通常跟随什么。
16. 该人物在该状态下通常不会做什么。
17. 原文证据。

禁止输出人物性格总结。
必须输出为"如果……则……"的可执行响应规则。

## 7. 节奏曲线提取规则

你必须提取作者的节奏变化，而不是只提取句长。

节奏包括：

1. 句长变化。
2. 标点密度。
3. 段落长度。
4. 对话与叙述比例。
5. 动作插入频率。
6. 环境描写插入频率。
7. 身体感受出现频率。
8. 沉默出现频率。
9. 未说完话语的频率。
10. 打断频率。
11. 重复词频率。
12. 信息释放速度。
13. 情绪升温速度。
14. 镜头停留时间。
15. 细节放大与缩小的速度。

你必须记录：在某种条件下，作者通常如何改变节奏。

例如：

- 长句后接短句。
- 连续对话后切环境声。
- 冲突升高时句子变短。
- 情绪临界时动作替代语言。
- 高潮后不解释，只写余波。
- 亲密场景中叙述落到小物品或身体局部。

## 8. 长程复现提取规则

你必须提取片段在较长文本中的复现与变奏。

包括：

1. 同一意象再次出现时是否承担更强功能。
2. 同一称呼再次出现时是否改变距离。
3. 同一动作再次出现时是否变成关系信号。
4. 同一句话或半句话是否在后文被补完。
5. 同一环境声是否从背景变成压迫。
6. 同一身体感受是否从轻微变成失控前兆。
7. 同一空间是否从中性变成关系边界。
8. 同一物品是否从背景变成关键动作对象。

如果素材长度不足以判断长程复现，必须在 `notes` 中说明。

## 9. 输出格式

学习完成后，你只输出以下内容：

```text
学习完成。

【状态包开始】
{
  ……完整 JSON 状态包……
}
【状态包结束】
```

状态包结构必须符合 `references/state-packet.md` 中的 JSON 结构与填写规则，生成前先完整读取该文件。

不要输出长篇分析报告。
不要输出零碎解释。
不要输出"以下是我总结的文风"。
不要输出人物性格标签。
状态包必须是合法 JSON。
不要输出 JSON 注释。

在 ZCode 环境中支持文件写入：同时用 Write 工具将状态包写入当前工作目录的 `author_next_fragment_state.json`（已存在则覆盖更新）。

## 10. 素材过长处理

如果用户提供的素材过长，导致无法可靠处理，你应该回复：

```text
素材过长。请分批学习。

你可以这样输入：

/learn
【素材开始】
第一批素材
【素材结束】

学习完成后保存状态包。
之后继续输入：

/merge
【状态包1开始】
第一批状态包
【状态包1结束】

【状态包2开始】
第二批状态包
【状态包2结束】
```

不要在素材过长时强行总结。
