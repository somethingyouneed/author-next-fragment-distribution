# author-next-fragment-distribution · 作者下一片段分布仿写

一个 [ZCode](https://github.com/) skill:**不总结文风,而是提取「片段转移网络」**——在什么上下文条件下,某个语言片段(一个语气词、一个标点习惯、一个称呼变化、一个动作、一种沉默方式……)出现后,作者更可能接什么、偶尔接什么、从不接什么——再据此仿写新场景,或检查已有正文是否偏离该网络。

## 它学什么 / 明确不学什么

**学:**

- 高牵引片段的上下文条件与后继分布(含负空间:作者在此通常**不写**什么)
- 人物状态机:可观察的**语言**状态(防备/试探/软化/回避……),不是性格标签
- 节奏规则、场景曲线、长程复现与变奏
- 片段在素材中的实际出现频次(`recurrence.count`)与语域档案(`prose_profile`)

**明确禁止:**

- 文风总结("细腻/冷峻/氛围感")
- 人物性格标签("傲娇/外冷内热")
- 剧情概括与主题升华

## 四个命令

| 命令 | 作用 |
| --- | --- |
| `/learn` | 学习素材,产出状态包(JSON) |
| `/merge` | 合并多个状态包(无损:去重 + 并证据,禁止数量上限式裁剪) |
| `/write` | 依据状态包 + 场景/人物/剧情目标仿写正文(写作前做语域校准) |
| `/check` | 检查正文是否偏离片段转移网络 |

```
/learn
【素材开始】
粘贴原文
【素材结束】
```

```
/write
【状态包开始】……【状态包结束】
【场景】雨夜,两人在楼道相遇。
【人物】A,B
【剧情目标】A想问B为什么骗他,但最后没问出口。
【触发片段】门、嗯、湿袖口
【字数】1500字左右
```

## 设计要点(来自实战教训)

- **频次回填**:`recurrence.count` 必须记录片段在素材中的实际出现次数。"高牵引"和"高频"是两回事——把醒目但低频的指纹(如独占一行的省略号对白)当文体主菜,会写出形似神非的文本。
- **语域档案**(`prose_profile`):平均句长、短句占比、感叹密度、对白比例。片段转移网络回答"在哪儿放什么",回答不了"句子长什么样";写作前从素材抽样实测并对齐。
- **合并无上限**:合并多个状态包只做去重 + 并证据 + 标注来源。数量上限会系统性删掉人物语音与单卷特有规律,只留下跨语料的标点级指纹。
- **激活预算只管用量**:单场景主动片段默认 ≤5 个,这是防堆砌的**使用**约束,永远不构成对状态包**存储**规模的限制;状态包过大时按人物/场景/层级检索切片。

## 安装

把整个目录拷入 ZCode 的技能目录之一:

- 用户级:`~/.agents/skills/author-next-fragment-distribution/`
- 项目级:`<项目>/.agents/skills/author-next-fragment-distribution/`

重载技能后,提到"学习/模仿某位作者的写作方式"或直接输入 `/learn` 即可触发。
